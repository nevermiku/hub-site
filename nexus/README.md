# 街尾之章 NEXUS — playable prototype

This is a newly reconstructed playable baseline, not a recovered copy of the missing original source.

## Included in v0.1
- Three sequential chapters: 4-person / 4-time logic deduction, one-true-statement deduction, Caesar cipher.
- Clues, hints, answer checking, chapter unlocks, memory fragments and local progress persistence.
- Responsive mobile-first interface and PWA shell.
- No external runtime dependencies.

## Known scope boundary
The original NEXUS project files were not found in the connected GitHub repositories. This baseline follows the surviving design notes only. It is a 2D narrative/puzzle prototype; original 3D character models, animation, voice acting, soundtrack and any unrecorded story content are not represented as recovered assets.

## Play
Open `index.html` locally or deploy this directory as a static site.
