# 三款游戏后续开发路线

分支：`games/2026-11-expansion`  
状态：开发中，尚未合并至 main 或触发生产部署。

## 0. 本轮已落地

### 街尾之章 NEXUS
- 新建独立目录 `nexus/`，不覆盖其他游戏。
- 形成可玩的三章推理原型：四人四时逻辑方阵、唯一真话、凯撒密码。
- 加入章节解锁、线索提示、记忆碎片、结局和本地自动存档。
- 采用移动端优先的响应式布局，无外部运行依赖。
- 这是依据现存设计线索重建的 v0.1 原型，不是从旧仓库恢复的原版代码。
- 当前仍缺：原版角色/剧情细节确认、3D角色模型与动画、配音、完整环境音乐、更多关卡、难度曲线、跨设备云存档。

## 1. 刀域突围 3D（game3d/）
现有基础：第三人称 3D 场景、战斗 HUD、技能栏、摇杆、地图、职业与装备系统、音效资源。

下一阶段按以下顺序推进：
1. 手机端操作体验：摇杆灵敏度、镜头转向、技能按钮热区、横竖屏提示和低性能设备帧率。
2. 新手引导：首次进入时用短步骤解释移动、普通攻击、技能、拾取和装备。
3. 战斗反馈：命中/格挡/暴击反馈、受击提示、Boss 阶段变化和技能冷却可读性。
4. Boss 音乐与环境音：按战斗状态切换，提供独立音量控制；沿用现有 sfx 目录，不删除旧音效。
5. 进度安全：检查本地存档结构、异常退出恢复、版本升级兼容和手动导出/导入。
6. 性能与兼容：低/中/高画质选项、设备像素比限制、资源加载失败提示。

## 2. 回声 ECHO（echo2d/ 与 echo3d/）
现有基础：2D 链式解谜与 3D 浮空回廊两个版本，均有章节/关卡界面、工具交互和 PWA 缓存。

下一阶段按以下顺序推进：
1. 关卡可读性：目标提示、可交互物高亮、失败原因说明与轻量新手教学。
2. 解谜体验：撤销一步、重置当前关卡、提示分级、通关用时与评价。
3. 进度体验：章节进度、已收集记忆/线索回看、离线存档和版本迁移。
4. 音频：环境氛围、解谜成功反馈和音量设置；不让音效遮盖提示文本。
5. 3D 版本性能：移动端帧率监控、远处物体简化、粒子/阴影质量选项。
6. 内容扩展：新增关卡前先建立难度梯度和关卡回归测试表，避免旧关卡被改坏。

## 3. 回归测试要求

每次更新至少检查：
- 手机 Chrome / Android：首次加载、刷新、返回、全屏、触控按钮。
- 桌面浏览器：键鼠操作、窗口缩放、刷新。
- PWA：安装、离线打开、缓存更新、旧缓存清理。
- 存档：刷新后保留、清空后重开、升级前后数据兼容。
- 资源：JS、图标、图片、音效、manifest 路径全部返回成功。
- 三款游戏的 URL 和目录互不覆盖。

## 4. 发布纪律

- 先在独立分支开发和检查，再提交 Pull Request。
- 未经确认不直接覆盖 main 生产版本。
- 腾讯云 EdgeOne Makers 项目若已连接本仓库，可配置为跟随发布分支自动部署；当前尚未取得该项目的控制台状态，因此不宣称已经部署。
- 国内正式访问优先使用已备案的自定义域名；平台预览地址不能当作长期正式链接。
